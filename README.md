# Web điều độ — bản chạy

Trang web điều độ container (bản đã build). Chỉ chứa `index.html`.

Mã nguồn, migration và tài liệu nằm ở repo riêng (private).
Mỗi lần cập nhật, file này được build lại bằng `build.py` từ `src/app.src.html`.

Khoá Supabase trong trang là **publishable key** — được phép công khai;
dữ liệu bảo vệ bằng Row Level Security và bảng phân quyền phía máy chủ.
